# How to install BepInEx
- Download the latest Bleeding Edge build (NOTE: Make sure you select the one labeled 'BepInEx Unity (IL2CPP) for Windows (x64) games')
- Extract the zip file.
- Put the contents of the extracted folder into the folder where GoreBox.exe is located (You can find it by going to Steam -> GoreBox -> Right Click -> Manage -> Browse local files)
